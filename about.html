About AeroCube

SYSTEM v1.0.0
PROJECT OVERVIEW

Smart Indoor Air Quality Monitor & Automator

AeroCube is an advanced IoT environmental monitoring system designed to track indoor air quality metrics in real-time. By utilizing industrial-grade sensors, it measures CO2 levels, Volatile Organic Compounds (VOCs), and Particulate Matter (PM1.0 to PM10.0). Coupled with automated smart outlets (AeroPlugs), the system intelligently mitigates poor air quality by triggering external ventilation and filtration systems automatically.

HARDWARE ARCHITECTURE
  • Microcontroller: ESP32 (Wi-Fi & ESP-NOW enabled)
  • CO2 / Temp / Humidity: Sensirion SCD41 (Photoacoustic NDIR)
  • VOC Index: Sensirion SGP40
  • Particulate Matter: Sensirion SPS30 (Laser Scattering)
  • Display: 2.4" TFT LCD (ST7789)
SOFTWARE STACK
  • Netlify: Netlify for Deployment
  • Backend / Database: Firebase Realtime Database
  • Firmware Environment: Arduino IDE / C++
  • Frontend Dashboard: HTML5, CSS3, Vanilla JavaScript
  • Iconography: Lucide Icons
