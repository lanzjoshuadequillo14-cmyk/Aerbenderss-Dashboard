About AeroCube

SYSTEM v1.0.0
PROJECT OVERVIEW

Smart Indoor Air Quality Monitor & Automator

AeroCube is an advanced IoT environmental monitoring system designed to track indoor air quality metrics in real-time. By utilizing industrial-grade sensors, it measures CO2 levels, Volatile Organic Compounds (VOCs), and Particulate Matter (PM1.0 to PM10.0). Coupled with automated smart outlets (AeroPlugs), the system helps users mitigates poor air quality by integrated automated outlets and providing insights and actionable recommendations.

SENSOR SUITE

Sensirion SCD41

Primary Function

Monitors absolute CO2 concentrations in parts-per-million (ppm), alongside ambient temperature and humidity.

Technology

Photoacoustic NDIR (Non-Dispersive Infrared) Sensing.

How it Works

An infrared emitter pulses light through the air. CO2 molecules absorb specific wavelengths, causing them to vibrate and create tiny pressure changes. A highly sensitive MEMS microphone detects these pressure changes as sound waves to determine CO2 density.

Sensirion SPS30

Primary Function

Detects and measures airborne particulate matter mass concentration across four distinct size bins: PM1.0, PM2.5, PM4.0, and PM10.0.

Technology

Laser Scattering (Optical Particle Counting).

How it Works

An internal fan draws ambient air through a chamber. A focused laser beam crosses the air stream, and as particles intersect the laser, they scatter light. A photodiode captures this scattered light to calculate particle mass. It also features an automated fan-cleaning mode to prevent long-term dust accumulation.

Sensirion SGP40

Primary Function

Detects complex indoor air pollutants from sources like cleaning agents, paints, aerosols, and cooking fumes, translating them into a standardized 0–500 VOC Index.

Technology

Metal-Oxide (MOx) Semiconductor Sensing.

How it Works

Contains a microscopic sensing element coated with a specialized metal-oxide material heated to a high temperature. Chemical vapors react with oxygen ions on this surface, altering the sensor's electrical resistance. This raw data is processed through an algorithm to calculate dynamic spikes in indoor chemical pollution.

HARDWARE ARCHITECTURE
  • Microcontroller: ESP32 (2.4 GHz Wi-Fi & )
  • CO2 / Temp / Humidity: Sensirion SCD41 (Photoacoustic NDIR)
  • VOC Index: Sensirion SGP40
  • Particulate Matter: Sensirion SPS30 (Laser Scattering)
  • Display: 2.4" TFT LCD (ST7789)
SOFTWARE STACK
  • Netlify: Netlify for Deployment
  • Backend / Database: Firebase Realtime Database
  • Firmware Environment: Arduino IDE / C++
  • Frontend Dashboard: HTML5, CSS3, Vanilla JavaScript
  • Iconography: Lucide Icons
