SPS30 Sensor Maintenance

SPS30 FAN CLEANING

The SPS30 particulate matter sensor has an internal fan-cleaning mechanism. Triggering this command starts a high-speed fan purge to remove accumulated dust from the sensor chamber, helping maintain particle measurement precision.

This command is handled entirely by the ESP32 firmware. The dashboard only sends the trigger signal to Firebase.

SCD41 CO₂ Calibration

SCD41 CO₂ FORCE RECALIBRATION

Force recalibration adjusts the SCD41 CO₂ sensor against fresh outdoor air.

Ensure the device has been exposed to fresh outdoor air (400 ppm) for at least 3 minutes before calibrating.

This command is handled entirely by the ESP32 firmware. The dashboard only sends the trigger signal to Firebase.

Confirm Sensor Cleaning

This will trigger the SPS30 fan-cleaning cycle on the AeroCube device. The cleaning operation will run automatically on the hardware side.

The ESP32 will reset the command back to false when cleaning is complete.
