Automation Thresholds

Fixed outlets: Outlet 1 turns ON when either the CO₂ or VOC trigger is active and turns OFF only when both triggers have cleared. Outlet 2 follows the PM2.5 trigger independently, using the live reading, not the dashboard’s 24-hour average.

Each sensor’s trigger activates at a reading greater than or equal to its threshold, clears below 85% of that threshold, and keeps its previous state between those limits. Hysteresis is fixed at 15%. Changing a threshold resets that sensor’s trigger before recalculation; changing modes resets all triggers.

Enter whole-number thresholds greater than zero. Save each field separately, or use Save Thresholds to validate and save each field independently. A save confirms the Firebase write. AeroCube reads the settings, calculates outputs, and sends relay commands approximately every five seconds, plus network time. Saving thresholds keeps the current mode. See AeroPlug Control for mode, manual requests, and reported outlet states.
